# Meadowland · 低多边形农场

**版本 0.3.0**

治愈系低多边形农场 3D 场景，**three.js r169 全新重写**（不是 fork 原站）。
参考 [Windland](https://windland-neotix.vercel.app/) 的观感与叙事结构，资产与内容全部程序化生成。

## 怎么打开（三种方式，从简单到正式）

### 方式 A：直接双击（最快）

```
farmland/standalone/index.html
```

**双击即可**。单文件 3.6 MB（内嵌 three.js + BGM），**不需要服务器、不需要联网、不需要装任何东西**。
把它发给别人、拷到 U 盘，同样能打开。

> 如果双击后是空白，看下一节「常见问题」。

### 方式 B：本地服务器（改代码用这个）

```bash
cd farmland
node serve.mjs
```

浏览器打开 **http://127.0.0.1:5173**

没有 node 的话，用 Python：

```bash
cd farmland/site
python -m http.server 8080
```

然后打开 **http://127.0.0.1:8080**

### 方式 C：标准开发流程（要改源码）

```bash
cd farmland
npm install
npm run dev        # 热更新开发
npm run build      # 产出 dist/
node bundle.mjs    # 重新生成 standalone/index.html
```

## 三个目录有什么区别

| 目录 | 说明 | 用途 |
|---|---|---|
| `standalone/` | **单文件 HTML**，全部内联 | 双击就能看，发给别人 |
| `site/` | 源码 + three 模块分开存放 | 用本地服务器跑（改代码不重新打包也能看） |
| `src/` | 原始源码，`import 'three'` 用裸模块名 | **真正改代码的地方** |

`site/` 由 `node prepare.mjs` 从 `src/` 生成（把裸模块名改成相对路径、拷贝 three）。
`standalone/` 由 `node bundle.mjs` 从 `site/` 生成（用 rollup 打包成一个文件）。

**改代码的正确流程**：改 `src/` → `node prepare.mjs` → 刷新浏览器；
要更新单文件再跑 `node bundle.mjs`。

## 常见问题

**双击打开是空白页？**

用 Chrome / Edge 打开。少数情况下浏览器对 `file://` 有限制，
换成方式 B（本地服务器）即可。

**页面出来了，但是纯色背景没有场景？**

说明 WebGL 初始化失败。检查：
1. 浏览器是否支持 WebGL（访问 `chrome://gpu` 看 WebGL 状态）
2. 显卡驱动 / 是否开了硬件加速
3. 远程桌面、虚拟机里通常没有 GPU，需要开启软件渲染

**卡顿？**

按 F12 打开控制台，输入：

```js
__APP__.renderer.info.render   // 看 draw call 和三角面数
```

正常应该是约 1080 个 draw call、约 165 万三角面（见下方「已实现」末尾的说明）。
如果是低端设备，可以改 `src/config.js` 里的 `WORLD.treeCount` 降低树的数量。

## 目录结构

```
farmland/
├─ standalone/index.html  ★ 单文件版，双击即可
├─ site/                  分离版（源码 + three）
├─ src/                   原始源码
│  ├─ main.js             装配：renderer、scene、世界、后期、主循环
│  ├─ config.js           ★ 所有"手感"参数（雾 / 光照 / 相机 / Bloom / 季节）
│  ├─ style.css           UI 样式（含竖屏适配）
│  ├─ util/               随机数、噪声、几何拼装
│  ├─ world/              地形、天空、树林、草、农场建筑、田地、道路、动物
│  ├─ render/             光照、后期管线
│  ├─ camera/             相机与开场运镜
│  ├─ ui/                 开场 / 菜单 / 交互
│  └─ audio/              WebAudio 合成环境音
├─ prepare.mjs            src -> site
├─ bundle.mjs             site -> standalone
├─ check-code.mjs         代码卫生检查（防止新旧代码并存）
├─ check-layout.mjs       场景元素重叠检查（建筑/田地/围栏/池塘）
├─ serve.mjs              零依赖静态服务器（不用 npm install）
└─ demo-*.html            各资产独立预览页（demo-bigtrees.html 等 9 个）
```

## 已实现

- **地形**：噪声高度场，中央平整台地 + 外圈山脊环抱
- **森林**：1170 棵松树 + 374 棵阔叶树，InstancedMesh 实例化
- **参天大树**：25 米地标巨树，**8 个品种可切换**（阔叶 / 凤凰木 / 仙人掌 / 紫叶 / 秋树 / 黄叶 / 粉花 / 绿金）
- **农场**：谷仓、农舍、双筒仓、水塔、风车（叶片旋转）、干草卷、围栏
- **建筑换风格**：谷仓 / 农舍 / 水塔 / 风车 / 筒仓 / 卡车 / 围栏，点击后弹出面板切换（5 种风格）
- **小树换品种**：橡树 / 白桦 / 云杉 / 秋树，4 个品种可切换
  - 各品种原始高度差很大（秋树 6.14、云杉 11.37），构建时按 `TREE_REF_H` **归一化**，换品种只换形态不换体量
- **农田**：3 块田垄，**8 种作物**可切换，每块独立围栏，土壤逐顶点贴合地形

  | 作物 | 颜色 |
  |---|---|
  | 小麦 | `#dfc062` 金黄 |
  | 卷心菜 | `#74b84e` 青绿 |
  | 南瓜 | `#e08a3c` 橙 |
  | 向日葵 | `#f0c04a` 亮黄 |
  | 玉米 | `#7ab05a` 翠绿 |
  | 胡萝卜 | `#5f9a3a` 深绿 |
  | 番茄 | `#5f9a44` 叶绿 + 红果 |
  | 薰衣草 | `#9a7ac8` 紫 |
- **四季**：春樱花 / 夏蜜蜂 / 秋落叶 + 南瓜 / 冬飘雪 + 雪人，滑杆无极过渡
  - 树上还有**积雪点**：按顶点法线朝上的面、按 x/z 网格列取最高点，贴在树冠顶面
  - 飘散碎片覆盖 254×254、离地 40 米
- **道路**：贴合地形的曲线道路，带中线，一辆车沿线行驶
- **农用卡车**：停在谷仓与农舍之间，带干草货斗、独立车轮和悬挂起伏
- **动画**：角色拆件 + 程序化关节动画（腿摆动 / 身体起伏 / 头部点头 / 尾巴摇摆 / 吃草低头），**无需骨骼**
- **动物**：8 牛、11 羊、8 鸡，**13 个品种**（荷斯坦/安格斯/海福特/西门塔尔/泽西 牛；白/黑/灰/棕/花 羊；来航/棕/黑/黄 鸡），全部限制在各自围栏内活动
- **人物**：3 个农场主沿路径走动 + 1 个坐在池塘边（双手撑膝）
- **鸟类**：14 只，3 种飞行模式（绕飞 / 横穿 / 螺旋），朝向用**解析切线**计算
- **猫头鹰**：停在风车屋顶，换风格时自动重新定位
- **昼夜**：光照 / 雾 / 曝光 / Bloom / 星空 / 夜灯全部联动，**滑杆无极调节**
- **夜间灯光**：建筑窗户发光 + 室内暖光 + 3 盏路灯（**径向衰减光斑** + 点光源照明）
- **开场**：点击「探索」后从**当前画面**平滑运镜到鸟瞰（3~6 秒自适应，无跳变）
- **特写相机**：点击物体自动飞行取景，**落点避障**（不会钻进树冠）
- **音频**：WebAudio 现场合成风声 + 鸟叫，零文件

| 指标 | 数值 |
|---|---|
| Draw call | 1084 |

## 迁移到另一台电脑

**最省事**：整个 `farmland/` 目录拷过去（不含 `node_modules`），然后：

```bash
cd farmland
node serve.mjs
```

`serve.mjs` **零依赖**，不需要 `npm install` —— 它只跑 `site/` 里的静态文件。

如果要改源码（`src/`），才需要装依赖：

```bash
npm install
node prepare.mjs     # src -> site
node bundle.mjs      # site -> standalone
```

依赖只有 `three@0.169` + `vite@5`，无平台相关代码。

**不想装环境？** 直接把 `standalone/index.html` 拷过去，双击就能看。
